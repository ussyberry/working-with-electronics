# Working with Electronics

Product creation with AI — designing new electronic products from first principles.

## Where we are

We are brainstorming a **new product**, separate from everything else in this repo. Nothing is decided yet. The old Tesla work below stays exactly as it is — reference material, not the current project.

## How we work — three departments

- **Design** — the thinking. Eclectic, like Leonardo da Vinci and Nikola Tesla: pull ideas from everywhere and combine them into something new. We design; we don't manufacture.
- **Manufacturing** — outsourced, Apple-style. Parts made all over the world, assembled by someone else. We own the design, not the factory.
- **Branding / Marketing** — the name and the story. Plan: acquire a defunct company name with history behind it. (Commodore was the first example — already taken, bought in July 2025. More names to come.)
